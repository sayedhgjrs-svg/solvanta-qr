How to Make a QR Code: A Practical Guide

A QR code is a square barcode that a phone camera can read. It can hold a web link, a WiFi login, an email address, a phone number or plain text. Making one takes under a minute. Making one that scans every time takes a few simple decisions, and this guide walks through them.

Make a QR code in five steps

  1. Open the free QR code generator.
  2. Pick the type: link or text, WiFi, email or phone.
  3. Type the content. The code updates as you type.
  4. Check the appearance: keep a dark code on a light background and leave the quiet zone at its default.
  5. Download a PNG for screens and documents, or an SVG for large prints. Then scan it with your phone before you share it.

Decide what the code should contain

  • A link. The most common choice. Use the final address people should land on, and prefer a short, stable URL. A long link with many tracking parameters makes a dense code that is harder to scan.
  • WiFi. The code carries the network name, password and security type, so guests can join by scanning. Anyone who scans it can read the password, so use a guest network when you can.
  • Email or phone. Scanning opens a pre-filled message or a dial screen. Include the country code in phone numbers.
  • Plain text. Useful for short notes, codes or serial numbers. Non-English text such as Arabic works because the text is encoded as UTF-8.

Static or dynamic?

A static code stores your content directly in the pattern. It cannot be edited later, but it has no expiry and does not depend on any service staying online. A dynamic code stores a short redirect address owned by a service, which can then point wherever you choose and may report scan counts. The trade-off is that the code only works while that service is running, and many services charge for it. Our generator makes static codes. If the destination might change, put a page you control behind the link and point the code at that page.

Make it scan every time

  • Contrast. Dark code on a light background is the safest. Inverted (light on dark) and low-contrast color pairs fail on many scanner apps.
  • Quiet zone. Keep the empty border around the code. Four modules (the small squares) is the usual standard. Do not crop it or place text against the edge.
  • Size. A common rule of thumb is a code about one tenth as wide as the scanning distance. For a printed card, use at least 2 cm (0.8 in) per side, and go larger for posters or windows.
  • Error correction. The four levels recover about 7%, 15%, 25% and 30% of damage. Higher levels cope with smudges but make the pattern denser. Medium is a good default.
  • Length. Less data means bigger squares and faster scanning.
  • Do not stretch or blur it. Never resize a QR image non-proportionally, and avoid enlarging a small PNG, which blurs the edges. Export again at a larger size, or use SVG.

Printing and display tips

  • Use SVG for anything printed large, because it stays sharp at any size.
  • Print on a flat, matte surface. Glossy paper, curved bottles and strong glare cause misreads.
  • Add a short call to action next to the code, such as "Scan to see the menu", so people know why to scan.
  • Print the web address in small text under the code as a fallback for people who cannot scan.
  • Always test the final print, in the real lighting, with at least two different phones.

If a code will not scan

  • Too small or too far away: enlarge it or move closer.
  • Low contrast or inverted colors: switch to dark on light.
  • Too much data: shorten the link or text.
  • Missing quiet zone or damaged print: reprint with a clear border, or raise the error correction.
  • Screen glare or a cracked screen: turn down reflections or print it instead.

Scanning safely

A QR code hides the address it opens, which scammers sometimes exploit by pasting a fake sticker over a real code. Before you open a result, read the preview address your phone shows and check that it matches the site you expect. Be careful with codes in unexpected emails, parking meters, or stickers that look stuck on top of something else. Do not enter passwords or payment details on a page you reached from a code you do not trust. If you display codes in a public place, check them regularly for tampering.

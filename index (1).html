How to make a QR code that scans reliably

Keep strong contrast. A dark code on a light background is the safest choice. Inverted codes (light on dark) and low-contrast colors fail on many scanner apps, so this tool warns you when the colors are risky.

Do not crop the quiet zone. The empty border around the code helps scanners find it. Four modules is the usual standard, which is the default here.

Shorter is simpler. The more characters you encode, the denser the pattern becomes and the larger it needs to be to scan. Use a short link instead of a long one when you can.

Choose the size for how it will be used. A common rule of thumb is to make the code about one tenth as wide as the distance it will be scanned from. For a printed card, aim for at least 2 cm (0.8 in) per side.

Error correction is a trade-off. Higher levels let a code survive smudges or a logo placed on top, but they add data and make it denser. Medium is a good default for most prints and screens.

Always test before you print. Scan the final file with at least two different phones, from the distance people will actually use.

Static codes only

This generator creates static QR codes. Your content is written directly into the image, nothing passes through our servers, and the code has no expiry date. The trade-off is that you cannot change the destination later: if the content changes, make a new code.

Privacy

Everything happens in your browser. The text, links and WiFi passwords you enter are not uploaded or stored by this page.

Frequently asked questions

Is the QR code generator free?

Yes. There is no sign-up and no watermark on the files you download.

Will my QR code stop working?

A static code keeps working as long as what it points to still exists. A link will stop being useful if the website behind it goes away.

PNG or SVG?

Use PNG for screens, documents and quick sharing. Use SVG when you will print large or resize the code, because it stays sharp at any size.

Can I use Arabic or other languages?

Yes. Text is encoded as UTF-8, so Arabic and other scripts work. Very long text makes a denser code.

Is it safe to put a WiFi password in a QR code?

Anyone who can scan the code can read the password. Display it only where you would be comfortable sharing the password, and use a guest network when possible.
